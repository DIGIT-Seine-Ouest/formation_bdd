# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

Support of the 1-hour **beginner, hands-on** session **« Valoriser le potentiel des données »** (DIGIT Formation, GPSO). Event pitch to deliver: *des données bien structurées permettent de gagner du temps et d'améliorer la lisibilité de l'information ; bonnes pratiques essentielles pour faciliter leur exploitation.*

**Content = the earlier "mobility" training (cheat sheet + guide de construction), lighter and told as a comic (BD).** Source of truth for the notions: the mobility `cheat_sheet.docx` / `guide_construction.docx` (git history, commit 3e53a75), transposed to bookshops. Core message: **séparer « j'écris » (base de terrain, a raw table) de « je fais la synthèse » (le bilan, computed)** — an aide-mémoire made for the eye is not a database made for the machine. A local Excel file, once structured, becomes a dashboard (internal) or an annuaire (external).

**Characters** (SVG, `src/components/Personnages.jsx`): **Rémi** (DSI GPSO, "Data Hero"; drawn, not his photo — the site is public) who asks Delos *everything*; **Delos** (the AI assistant, teal eye — it does the teaching, gently at Rémi's expense); **Mme Tartempion** (invented, deliberately improbable name so no real person feels targeted; brings the 3 questions); **La DIGIT**.

Storyline (one file per episode in `src/slides/`):
0. `Ouverture` — cover + casting.
1. `Ep1Mission` — Rémi is asked (big office scene `Bureau`) to build "une base de données des librairies pour un suivi interne", **with no precise question**. Teaser: he already made a file on Friday 17:45, "vite fait".
2. `Ep2Theorie` — « Delos, c'est quoi une base de données ? » → BIM, 2 slides: (1) shopping list → ARTICLE → table; (2) rebound on **entité = LIBRAIRIE**: the table is built element by element on click (entité → attributs from the 4 objectives → enregistrement → valeur → identifiant), each definition with its « courses » equivalent, then the test de la phrase and Delos launching the Excel build. Delos only teases « le total, on le calculera à part ».
3. `Ep3Tuto` — **le tuto de Delos**, 9 étapes (data `ETAPES`) : chaque étape = question de Rémi → théorie courte de Delos → ⚠️ piège (erreur du fichier de vendredi) → 💡 geste Excel. Visuel : `<Excel>` Windows avec `etapeSaisie(n)` (étape 9 : l’onglet `synthese`, tableau `SYNTH`), le bouton du ruban entouré et la boîte de dialogue en fragment. Étapes : en-têtes depuis les objectifs · une ligne = une librairie + Ctrl+T · une case = une info · rien dans la couleur + MFC · listes déroulantes · identifiant · jointure RECHERCHEV + `communes` · `annee_suivi` · then the slide « j'écris ≠ je fais la synthèse » (liste = j'écris, ticket de caisse = synthèse; it lives here, not in Ép. 2, because Rémi needs it right before his totals) · synthese ; puis une slide Bonus TCD (boîte « Tableau croisé dynamique à partir d’un tableau ou d’une plage » + volet des champs). Puis Mme Tartempion obtient ses 3 réponses en 10 s (Q3 : Ville-d’Avray).
4. `Ep4Pratique` — « À vous ! » : le fichier de vendredi (`vaVite()`), 7 repères en fragments, minuteur 8 min, lien de téléchargement ; correction : 7 erreurs évident → subtil, chacune renvoyant à son étape.
5. `Ep5Valoriser` — call to the DIGIT, live city pages (`Vitrine` iframes: Meudon, Sèvres, Boulogne), chain poste de Rémi → portail local → base nationale → tout le monde.
6. `Final` — what Rémi learned + the kit to download.

Data (`src/remi.js`): 17 GPSO bookshops from *Base des librairies en France* (Ministère de la Culture, data.gouv.fr, LO 2.0; Chaville included, Saint-Cloud is not GPSO) + legal populations (geo.api.gouv.fr). Never invent facts about the real bookshops (Rémi's "Visite" column is his own internal note).

## Kit (`public/ressources/`, generated by `python3 scripts/build_ressources.py`, needs openpyxl + python-docx)
`exercice_aide_memoire.xlsx` (= the Friday file `VA_VITE`: one sheet with merged town cells, colours, lists in cells, TOTAL, stale « Récap (2) »), `correction_suivi_librairies.xlsx` (saisie = Excel table `T_saisie` id · librairie · assortiment · label · code_commune · commune (RECHERCHEV) · annee_suivi, with dropdowns + MFC `=$D2="LIR"` · listes · communes · synthese with formulas · **TCD** (added in real Excel: the script won't overwrite this file unless `--correction`) · dictionnaire), `cheat_sheet_librairies.docx`, `guide_construction_librairies.docx`. The Excel screens in the slides must match these files (tabs, cells, formulas).

## Stack

Vite + React + Reveal.js 5 (`npm run dev`, `npm run build`), deployed to GitHub Pages by `.github/workflows/deploy.yml` on push to `main` (base path `/formation_bdd/`). Live iframes → internet needed during the session.

| Path | Role |
|---|---|
| `src/App.jsx` | Reveal init; relays `slidechanged` as a `reveal:slidechanged` window event (iframes load only when visible) |
| `src/components/BD.jsx` | `Bulle`, `Case`, `Narrateur`, `Planche`, `Chapitre`, `Mini` |
| `src/components/Bureau.jsx` | Rémi's office, big, with a screen slot (mail, Delos chat…) |
| `src/components/Excel.jsx` | Realistic Excel window (ribbon, name box, formula bar, grid, sheet tabs) |
| `src/components/Vitrine.jsx` | City pages in iframes |

Gotchas: JS strings with French apostrophes → use the typographic ’ or template literals; never mass-replace quotes with sed/regex (it broke template literals once). Design tokens: `--blue #009fe3`, `--green #95c11f`, `--navy #0f4c75`, `--yellow #ffe066`; fonts Bangers (BD titles), Comic Neue (bubbles), IBM Plex Serif, Roboto.

## Excel screens = HTML rebuilds of Excel for **Windows** (Microsoft 365, French UI)
No screenshots (they were illegible and Mac-looking; removed 17/11/2026). `src/components/Excel.jsx` draws a Windows window (green title bar with ─ ☐ ✕, ribbon tabs Fichier…Aide, optional ribbon command row with the button to click outlined in red, name box, formula bar with ✕ ✓ fx, grid, sheet tabs) + `Dialogue` and widgets (`XOnglets`, `XCase`, `XRadio`, `XListe`, `XChamp`, `XBoutons`) + `PanneauTCD` (« Champs de tableau croisé dynamique », zones Filtres/Colonnes/Lignes/Valeurs). Shortcuts are Windows ones (Ctrl, never ⌘).
